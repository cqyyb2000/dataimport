## 环境管理命令

### 激活虚拟环境
```bash
# Windows
.venv\Scripts\activate

# Linux/Mac
source .venv/bin/activate
```

### 安装依赖
```bash
pip install -r requirements.txt
```

### 更新依赖清单
```bash
pip freeze > requirements.txt
```

### 退出虚拟环境
```bash
deactivate
```
