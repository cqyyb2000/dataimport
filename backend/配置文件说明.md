# 档案管理系统配置文件说明

## 配置文件结构

系统使用 `set.config` 配置文件来管理各种配置参数，该文件采用 INI 格式，包含以下几个主要配置段：

### 1. 数据库配置 [DATABASE]

| 参数名 | 说明 | 默认值 | 示例 |
|--------|------|--------|------|
| DB_HOST | 数据库服务器地址 | localhost | localhost |
| DB_PORT | 数据库端口 | 3306 | 3306 |
| DB_USER | 数据库用户名 | root | root |
| DB_PASSWORD | 数据库密码 | cqyyb031125 | your_password |
| DB_NAME | 数据库名称 | docwebdb | docwebdb |
| DB_CHARSET | 字符集 | utf8mb4 | utf8mb4 |

### 2. 安全配置 [SECURITY]

| 参数名 | 说明 | 默认值 | 示例 |
|--------|------|--------|------|
| SECRET_KEY | Flask应用密钥 | key031125 | your_secret_key |
| JWT_SECRET_KEY | JWT令牌密钥 | jwt_key031125 | jwt_secret |
| JWT_ACCESS_TOKEN_EXPIRES | JWT令牌过期时间(秒) | 3600 | 3600 |

### 3. 文件上传配置 [UPLOAD]

| 参数名 | 说明 | 默认值 | 示例 |
|--------|------|--------|------|
| UPLOAD_FOLDER | 上传文件夹 | uploads | uploads |
| MAX_CONTENT_LENGTH | 最大文件大小(字节) | 104857600 | 104857600 (100MB) |
| ALLOWED_EXTENSIONS | 允许的文件扩展名 | pdf,doc,docx,jpg,jpeg,png,txt,xlsx,xls,ppt,pptx,zip,rar | pdf,doc,docx |
| UPLOAD_PATH | 上传路径 | uploads | uploads |
| FILE_NAME_LENGTH | 文件名最大长度 | 255 | 255 |
| UPLOAD_TIMEOUT | 上传超时时间(秒) | 300 | 300 |

### 4. 应用配置 [APPLICATION]

| 参数名 | 说明 | 默认值 | 示例 |
|--------|------|--------|------|
| DEBUG | 调试模式 | False | True/False |
| HOST | 服务器地址 | 0.0.0.0 | 0.0.0.0 |
| PORT | 服务器端口 | 5000 | 5000 |
| THREADED | 多线程模式 | True | True/False |

### 5. 日志配置 [LOGGING]

| 参数名 | 说明 | 默认值 | 示例 |
|--------|------|--------|------|
| LOG_LEVEL | 日志级别 | INFO | DEBUG/INFO/WARNING/ERROR |
| LOG_FILE | 日志文件路径 | logs/app.log | logs/app.log |
| LOG_MAX_SIZE | 日志文件最大大小(字节) | 10485760 | 10485760 (10MB) |
| LOG_BACKUP_COUNT | 日志备份文件数量 | 5 | 5 |

## 使用方法

### 1. 修改配置文件

直接编辑 `set.config` 文件，修改相应的参数值：

```ini
[DATABASE]
DB_HOST = localhost
DB_PORT = 3306
DB_USER = root
DB_PASSWORD = your_password
DB_NAME = docwebdb
```

### 2. 在代码中使用配置

```python
from config_reader import config_reader

# 获取数据库配置
db_config = config_reader.get_database_config()
db_uri = config_reader.get_database_uri()

# 获取上传配置
upload_config = config_reader.get_upload_config()
max_size = upload_config['max_content_length']

# 使用通用方法获取单个配置
host = config_reader.get('DATABASE', 'DB_HOST', 'localhost')
port = config_reader.getint('DATABASE', 'DB_PORT', 3306)
debug = config_reader.getboolean('APPLICATION', 'DEBUG', False)
```

### 3. 查看当前配置

运行配置示例脚本：

```bash
python config_example.py
```

## 注意事项

1. **配置文件路径**: 配置文件应放在项目根目录下，文件名为 `set.config`
2. **字符编码**: 配置文件使用 UTF-8 编码
3. **敏感信息**: 数据库密码等敏感信息建议使用环境变量或加密存储
4. **配置验证**: 系统启动时会验证配置文件格式和必要参数
5. **默认配置**: 如果配置文件读取失败，系统会使用内置的默认配置

## 配置文件示例

完整的 `set.config` 文件示例：

```ini
# 档案管理系统配置文件
# Database Configuration - 数据库配置
[DATABASE]
DB_HOST = localhost
DB_PORT = 3306
DB_USER = root
DB_PASSWORD = cqyyb031125
DB_NAME = docwebdb
DB_CHARSET = utf8mb4

# Security Configuration - 安全配置
[SECURITY]
SECRET_KEY = key031125
JWT_SECRET_KEY = jwt_key031125
JWT_ACCESS_TOKEN_EXPIRES = 3600

# File Upload Configuration - 文件上传配置
[UPLOAD]
UPLOAD_FOLDER = uploads
MAX_CONTENT_LENGTH = 104857600
ALLOWED_EXTENSIONS = pdf,doc,docx,jpg,jpeg,png,txt,xlsx,xls,ppt,pptx,zip,rar
UPLOAD_PATH = uploads
FILE_NAME_LENGTH = 255
UPLOAD_TIMEOUT = 300

# Application Configuration - 应用配置
[APPLICATION]
DEBUG = False
HOST = 0.0.0.0
PORT = 5000
THREADED = True

# Logging Configuration - 日志配置
[LOGGING]
LOG_LEVEL = INFO
LOG_FILE = logs/app.log
LOG_MAX_SIZE = 10485760
LOG_BACKUP_COUNT = 5
```

## 故障排除

1. **配置文件不存在**: 检查 `set.config` 文件是否在项目根目录
2. **配置读取失败**: 检查配置文件格式是否正确，参数名称是否拼写正确
3. **数据库连接失败**: 检查数据库配置参数是否正确
4. **文件上传失败**: 检查上传目录权限和文件大小限制
5. **日志记录失败**: 检查日志目录权限和磁盘空间
