## 1. 项目概述

### 1.1 项目名称
会计核算数据引入平台（Accounting Data Import Platform）

### 1.2 项目目标
开发一个统一的数据引入平台，支持将符合GB/T 24589.2-2010标准的会计核算数据（公共档案和总账）引入到系统中，实现多单位、多账套的独立管理和数据整合。

**核心特性**：
- 支持每个账套导入本单位不同年度的会计核算数据
- 不同年度的数据在账套内独立存储和管理
- 支持跨年度数据查询、对比和分析

### 1.3 项目范围
- **支持的数据类型**：
  - 公共档案类数据（SHARE.xml）
  - 总账类数据（GL.xml）
- **支持的格式**：GB/T 24589.2-2010标准XML格式
- **核心功能**：数据导入、数据验证、账套管理、数据查询

### 1.4 目标用户
- 财务管理人员
- 系统管理员
- 审计人员
- 数据分析人员

## 2. 需求背景

### 2.1 业务背景
随着行政事业单位会计核算的标准化和信息化发展，各单位使用不同的会计核算软件，但都遵循GB/T 24589.2-2010标准输出数据。需要一个统一平台来：
- 整合不同单位的会计核算数据
- 支持多账套独立管理
- 提供统一的数据查询和分析能力

### 2.2 现状问题
- 各单位数据分散，难以统一管理
- 数据格式虽然标准，但缺乏统一的引入平台
- 无法实现跨单位的数据对比和分析
- 数据验证和错误处理机制不完善

### 2.3 解决方案
开发统一的数据引入平台，实现：
- 标准化的数据导入流程
- 多账套独立管理（一个账套对应一个单位）
- **多年度数据管理**（每个账套可导入本单位多个年度的数据）
- 完善的数据验证机制
- 统一的数据查询和分析接口
- 支持跨年度数据查询和对比分析

## 3. 功能需求

### 3.1 账套管理

#### 3.1.1 账套创建
**功能描述**：创建新的账套，用于存储不同单位的会计核算数据

**输入**：
- 账套编码（必填，唯一标识）
- 账套名称（必填）
- 会计核算单位名称（必填）
- 组织机构代码（可选）
- 单位类型（行政单位/事业单位）
- 备注信息（可选）

**输出**：
- 账套创建成功提示
- 账套基本信息

**重要说明**：
- 账套创建后，可以导入该单位多个年度的会计核算数据
- 每个账套的数据按年度进行组织和存储
- 支持逐年导入，也支持一次性导入多个年度的数据

**业务规则**：
- 账套编码必须唯一
- 账套编码建议使用组织机构代码或自定义编码
- 一个账套对应一个单位的会计核算数据
- **重要**：每个账套可以导入本单位不同年度的相关数据，支持多年度数据共存

#### 3.1.2 账套查询
**功能描述**：查询系统中所有账套信息

**输入**：
- 查询条件（账套编码、账套名称、单位名称等）
- 分页参数（页码、每页数量）

**输出**：
- 账套列表（包含账套编码、名称、单位名称、创建时间、数据状态等）
- **已导入数据年度列表**（显示该账套已导入哪些年度的数据）
- 分页信息

**业务规则**：
- 支持模糊查询
- 支持按创建时间排序
- 支持按数据状态筛选（已导入/未导入）
- 显示每个账套已导入的数据年度范围

#### 3.1.3 账套编辑
**功能描述**：编辑账套基本信息

**输入**：
- 账套编码（不可修改）
- 账套名称（可修改）
- 其他可修改字段

**输出**：
- 更新成功提示

**业务规则**：
- 账套编码创建后不可修改
- 已有数据的账套，部分字段不可修改

#### 3.1.4 账套删除
**功能描述**：删除账套及其所有数据

**输入**：
- 账套编码
- 确认操作

**输出**：
- 删除成功提示

**业务规则**：
- 删除前需要二次确认
- 删除操作不可恢复
- 建议先备份数据再删除

### 3.2 数据导入

#### 3.2.1 公共档案导入
**功能描述**：导入公共档案类XML文件（SHARE.xml）

**输入**：
- 账套编码（必填，选择目标账套）
- XML文件（必填，符合GB/T 24589.2-2010标准）
- 导入选项：
  - 是否覆盖已有数据（默认：否）
  - 是否验证数据完整性（默认：是）
  - 是否验证数据逻辑性（默认：是）

**输出**：
- 导入进度提示
- 导入结果报告：
  - 成功导入的记录数
  - 失败的记录数及失败原因
  - 数据验证结果

**业务规则**：
- 文件必须是有效的XML格式
- 必须符合GB/T 24589.2-2010标准结构
- 电子账簿信息必须与账套信息匹配（会计核算单位必须一致）
- 支持增量导入和全量导入
- **重要**：支持同一账套导入不同年度的公共档案数据
- 不同年度的公共档案数据可以共存（如科目、内设机构等可能跨年度使用）
- 导入前进行数据验证

**数据验证规则**：
- XML格式验证
- 必填字段验证
- 数据格式验证（日期、数值等）
- 编码唯一性验证
- 关联数据一致性验证

#### 3.2.2 总账数据导入
**功能描述**：导入总账类XML文件（GL.xml）

**输入**：
- 账套编码（必填，选择目标账套）
- XML文件（必填，符合GB/T 24589.2-2010标准）
- 导入选项：
  - 是否覆盖已有数据（默认：否）
  - 是否验证凭证借贷平衡（默认：是）
  - 是否验证科目余额一致性（默认：是）
  - 导入范围（全部/指定年度/指定期间）

**输出**：
- 导入进度提示
- 导入结果报告：
  - 成功导入的凭证数量
  - 成功导入的分录行数量
  - 成功导入的科目余额数量
  - 失败的记录数及失败原因
  - 数据验证结果

**业务规则**：
- 文件必须是有效的XML格式
- 必须符合GB/T 24589.2-2010标准结构
- 凭证分录必须借贷平衡
- 科目余额必须与凭证数据一致
- 导入前必须已导入公共档案数据
- **重要**：支持同一账套导入不同年度的总账数据
- 不同年度的凭证、科目余额等数据可以共存于同一账套中
- 支持按年度、按期间导入
- 导入时需指定或识别数据所属的会计年度

**数据验证规则**：
- XML格式验证
- 凭证借贷平衡验证
- 科目余额一致性验证
- 会计期间连续性验证
- 辅助核算数据一致性验证

#### 3.2.3 批量导入
**功能描述**：支持同时导入多个文件或多个账套的数据

**输入**：
- 文件列表（支持多选）
- 账套映射关系（文件与账套的对应关系）
- 导入选项

**输出**：
- 批量导入进度
- 每个文件的导入结果
- 汇总报告

**业务规则**：
- 支持同时导入多个文件
- 支持为不同文件指定不同账套
- **重要**：支持同一账套导入多个不同年度的文件
- 支持导入失败后继续处理其他文件

#### 3.2.4 导入历史查询
**功能描述**：查询历史导入记录

**输入**：
- 查询条件（账套、导入时间、文件名称、**会计年度**等）
- 分页参数

**输出**：
- 导入历史列表
- 每条记录的详细信息（导入时间、文件名称、**数据年度**、导入结果、记录数等）

**业务规则**：
- 记录每次导入的详细信息，包括数据所属的会计年度
- 支持按时间、账套、**年度**等条件查询
- 支持查看导入详情和错误信息
- 可以查看每个账套已导入的年度列表

### 3.3 数据验证

#### 3.3.1 文件格式验证
**功能描述**：验证XML文件格式是否符合标准

**验证项**：
- XML格式正确性
- 命名空间正确性
- 根元素正确性
- 字符编码（UTF-8）

**输出**：
- 验证结果（通过/失败）
- 错误信息（如有）

#### 3.3.2 数据完整性验证
**功能描述**：验证必填字段是否完整

**验证项**：
- 电子账簿必填字段
- 会计期间必填字段
- 会计科目必填字段
- 凭证必填字段
- 分录行必填字段

**输出**：
- 验证结果
- 缺失字段列表

#### 3.3.3 数据格式验证
**功能描述**：验证数据格式是否符合规范

**验证项**：
- 日期格式（YYYYMMDD）
- 数值格式（精度、小数位数）
- 编码格式
- 字符长度

**输出**：
- 验证结果
- 格式错误列表

#### 3.3.4 数据逻辑验证
**功能描述**：验证数据逻辑是否正确

**验证项**：
- 凭证借贷平衡
- 科目余额一致性
- 会计期间连续性
- 辅助核算数据一致性
- 科目层级关系
- 编码唯一性

**输出**：
- 验证结果
- 逻辑错误列表

#### 3.3.5 关联数据验证
**功能描述**：验证关联数据是否存在

**验证项**：
- 凭证中的科目是否在科目表中存在
- 分录行中的辅助核算项是否在档案中存在
- 科目余额中的科目是否在科目表中存在
- 凭证类型是否在凭证类型表中存在

**输出**：
- 验证结果
- 关联错误列表

### 3.4 数据查询

#### 3.4.1 账套数据查询
**功能描述**：查询指定账套的数据

**输入**：
- 账套编码（必填）
- 查询类型（公共档案/总账数据）
- **会计年度**（可选，支持按年度筛选，支持多选年度）
- 查询条件

**输出**：
- 查询结果列表
- 分页信息
- 年度统计信息（显示账套中包含哪些年度的数据）

**业务规则**：
- 支持按年度筛选查询
- 支持跨年度查询（不选择年度时查询所有年度）
- 支持多年度数据对比

#### 3.4.2 公共档案查询
**功能描述**：查询公共档案数据

**支持查询**：
- 电子账簿信息
- 会计期间信息（**支持按年度查看各年度的期间设置**）
- 内设机构信息
- 会计科目信息（**支持查看不同年度的科目设置变化**）
- 科目辅助核算信息
- 币种信息
- 汇率信息（**支持按年度查看汇率信息**）
- 项目信息
- 部门信息
- 人员信息
- 单位往来信息
- 个人往来信息

**输入**：
- 账套编码
- 档案类型
- **会计年度**（可选，支持按年度筛选）
- 查询条件（编码、名称等）

**输出**：
- 档案数据列表
- 详细信息
- **年度版本信息**（如科目在不同年度的变化）

**业务规则**：
- 支持按年度查看档案数据
- 支持查看档案数据在不同年度的变化情况
- 某些档案（如科目）可能跨年度使用，查询时需明确年度范围

#### 3.4.3 总账数据查询
**功能描述**：查询总账数据

**支持查询**：
- 记账凭证
- 记账凭证分录行
- 科目余额

**输入**：
- 账套编码
- 查询类型
- **会计年度**（可选，支持按年度筛选，支持多选年度）
- **会计期间号**（可选，支持按期间筛选）
- 查询条件（凭证编号、科目编号、凭证期范围等）

**输出**：
- 查询结果分页显示列表
- 详细信息
- 年度,会计期间,凭证号，凭证金额，凭证日期，制单人，审核人

**业务规则**：
- 支持按年度、按期间筛选查询
- 支持跨年度、跨期间查询
- 支持多年度数据对比分析
- 科目余额查询时，支持按年度、按期间查看期初余额、本期发生额、期末余额

#### 3.4.4 跨账套查询
**功能描述**：支持跨多个账套的数据查询和对比

**输入**：
- 账套列表（多选）
- **会计年度**（可选，支持按年度筛选，支持多选年度）
- 查询条件

**输出**：
- 多账套数据对比结果
- 汇总统计信息
- **按年度分组统计**

**业务规则**：
- 支持选择多个账套进行查询
- 支持数据对比分析
- 支持汇总统计
- **支持跨账套、跨年度的数据对比分析**
- 支持按年度维度进行多账套数据对比

### 3.6 多年度数据管理

#### 3.6.1 多年度数据存储
**功能描述**：系统支持每个账套存储多个年度的会计核算数据

**设计原则**：
- 每个账套对应一个会计核算单位
- 每个账套可以导入该单位多个年度的数据
- 不同年度的数据在账套内按年度进行组织和存储
- 年度数据之间相互独立，互不影响

**数据组织方式**：
- 公共档案数据：按年度存储，支持跨年度使用（如科目、内设机构等）
- 总账数据：按年度、按期间存储（凭证、科目余额等）
- 每个年度数据包含完整的会计期间定义

#### 3.6.2 年度数据识别
**功能描述**：系统能够识别和区分不同年度的数据

**识别方式**：
- 从XML文件的`电子账簿`元素中读取`会计年度`字段
- 从`会计期间`元素中识别年度信息
- 从`记账凭证`、`科目余额`等元素中识别年度信息
- 导入时自动识别数据所属年度，无需手动指定

**业务规则**：
- 同一账套导入的数据，会计核算单位必须一致
- 不同年度的数据可以共存
- 支持逐年导入，也支持一次性导入多个年度
- 导入时自动验证年度数据的完整性和一致性

#### 3.6.3 年度数据查询
**功能描述**：支持按年度查询和跨年度查询

**查询方式**：
- 按年度查询：指定单个或多个年度进行查询
- 跨年度查询：不指定年度，查询所有年度数据
- 年度对比：对比不同年度的数据变化

**应用场景**：
- 查看某账套某年度的凭证、余额等数据
- 对比不同年度的科目设置变化
- 分析跨年度的财务数据趋势
- 生成年度报表和统计信息

#### 3.6.4 年度数据管理
**功能描述**：管理账套中的年度数据

**管理功能**：
- 查看账套已导入的年度列表
- 查看每个年度的数据统计信息（凭证数量、科目数量等）
- 按年度导出数据
- 按年度删除数据（需谨慎操作）

**业务规则**：
- 年度数据删除前需要二次确认
- 删除年度数据会影响该年度的所有相关数据
- 建议删除前先备份数据

## 4. 非功能需求

### 4.1 性能需求

#### 4.1.1 响应时间
- 页面加载时间：< 2秒
- 数据查询响应时间：< 3秒（单账套，10万条记录内）
- 数据导入处理速度：> 1000条/秒
- 文件上传响应时间：< 5秒（100MB以内）

#### 4.1.2 并发性能
- 支持至少50个并发用户
- 支持至少10个并发导入任务
